# Miniaturas de Videos

Este directorio contiene las miniaturas optimizadas para la galería de videos. Las miniaturas son versiones estáticas y ligeras de los videos que se utilizan como placeholders mientras se cargan los videos completos.

Para generar las miniaturas:
1. Extraer un fotograma representativo de cada video
2. Optimizar la imagen resultante (formato JPG)
3. Nombrar cada miniatura con el mismo número que su video correspondiente

Ejemplo:
- video1.mp4 -> 1.jpg
- video2.mp4 -> 2.jpg

Las miniaturas deben tener una resolución adecuada para mantener la calidad visual mientras se optimiza el tamaño del archivo.
